# 이지스자산운용 헤지펀드운용파트 지원 포트폴리오

김재원의 시장 리서치, 운용자료 관리, AI 업무 자동화 경험을 정리한 정적 웹 포트폴리오입니다.

- 공개 웹페이지: https://bucheoncityboy.github.io/igis-hedge-fund-portfolio/
- 웹 파일: `docs/`
- 편집용 내용: `content.json`
- Markdown 원본: `igis_hedge_fund_portfolio.md`

## 편집

`content.json`의 내용을 수정하고 `python build.py`를 실행하면 웹페이지와 Markdown을 함께 갱신합니다. 스타일은 `docs/styles.css`에서 수정합니다. Markdown을 직접 편집할 수도 있으나 빌드하면 `content.json`을 기준으로 덮어씁니다.

## 배포

GitHub Pages의 소스를 `main` 브랜치 `/docs`로 설정합니다. 외부 서비스나 서버, API 키가 필요하지 않습니다. 원문 아카이브 PDF와 개인 자료는 이 저장소에 포함하지 않습니다.

## 화면 및 인쇄

데스크톱과 모바일을 지원하며 브라우저 인쇄 시 A4 세로 5개 섹션으로 구성합니다. 외부 폰트에 의존하지 않고 시스템 한국어 폰트를 사용합니다.

## 사실관계

제공된 경력기술서와 자기소개서의 수행 내용을 우선 사용하고 각 프로젝트의 공개 README 및 산출물과 비교했습니다. 코드 테스트 수치는 기존 검수 기록이며 이번 포트폴리오 제작에서 프로젝트를 다시 실행한 결과는 아닙니다. 실제 브로커 체결이나 실계좌 수익률은 주장하지 않습니다.
